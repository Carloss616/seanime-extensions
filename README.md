# seanime-extensions

Personal collection of [seanime](https://github.com/5rahim/seanime) extensions.

Official docs: <https://seanime.gitbook.io/seanime-extensions>

## Layout

```
src/<type>/<id>/
  code.ts                  TS source (the file you edit)
  manifest.template.json   manifest with "payload": "__PAYLOAD__"
  <id>.js                  built JS (regenerated by build.py)
  <id>.json                built manifest (regenerated by build.py)
  README.md
types/
  core.d.ts                runtime globals (fetch, $sleep, ...)
  custom-source.d.ts       CustomSource + AL_* subset
                           — add manga-provider.d.ts, plugin.d.ts, etc.
                             when you start writing those types of extensions
marketplace.json           auto-generated index — never edit by hand
build.py                   build all + regen marketplace.json
tsconfig.json              shared TS config (no emit; IDE/typecheck only)
```

`<type>` is one of: `custom-source`, `manga-provider`, `anime-torrent-provider`, `onlinestream-provider`, `plugin`.

## Build

Requires Python 3 and `npx` (esbuild is fetched on demand).

```bash
python3 build.py                      # build everything + regen marketplace.json
python3 build.py mangaupdates         # build one extension by id
python3 build.py id1 id2              # build several
python3 build.py --no-marketplace     # skip marketplace regen
```

The script walks `src/` for every `manifest.template.json`, transpiles the
sibling `code.ts` via esbuild, and writes `<id>.js` + `<id>.json` next to it.
Then it overwrites `marketplace.json` with one entry per built extension —
**don't edit `marketplace.json` by hand, your changes will be lost**.

## Adding a new extension

```bash
python3 build.py new custom-source my-source
```

That creates `src/custom-source/my-source/` with a stub `code.ts`,
`manifest.template.json`, and `README.md`. Then:

1. Implement the methods in `code.ts` (see `types/custom-source.d.ts` for the contract; for other types, fetch the relevant `.d.ts` from the seanime repo into `types/`).
2. Fill in `description`, `author`, `icon`, etc. in `manifest.template.json`.
3. `python3 build.py my-source` to build.
5. Commit the source + built artifacts.

Each `<type>` directory is just a folder convention — `build.py` accepts any
subfolder under `src/` containing both `code.ts` and `manifest.template.json`.

## Install in seanime

**Local** (no hosting): copy the built `<id>.json` into `$SEANIME_DATA_DIR/extensions/` and reload extensions.

**Self-hosted marketplace** (lets you install all your extensions from the UI): push this repo to GitHub, then in seanime → Settings → Extensions, set the marketplace URL to:
```
https://raw.githubusercontent.com/Carloss616/seanime-extensions/refs/heads/main/marketplace.json
```

**Single extension install**: in seanime → Add Extension → paste the raw URL of a specific `<id>.json`.
